# Python Projects

Small Python projects built to practise programming fundamentals and useful standard-library tools.

- [Password Generator](./password-generator): Tkinter desktop UI using the secure `secrets` module.
- [Expense Tracker](./expense-tracker): Tkinter desktop UI backed by SQLite.

Each project has its own README and unit tests. Run tests from each project directory with `python -m unittest discover -s tests -v`.
