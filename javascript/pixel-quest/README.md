# Pixel Quest 🎮

A tiny 2D pixel-art platform game made with vanilla HTML, CSS and JavaScript.

## Play
Open **index.html** in a browser, or enable GitHub Pages for this folder.

## Controls
- Move: **A / D** or **← / →**
- Jump: **Space**, **W** or **↑**
- Mobile: use the on-screen buttons
- Collect all **5 gems** and avoid the slimes.

## Features
- Canvas-based pixel-art scene
- Platform jumping and simple enemy patrols
- Collectibles, score counter, win/lose states
- Keyboard and touch controls
- No libraries or installation required
